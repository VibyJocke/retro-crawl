# Retro Crawl
Retro Crawl is a hobby project loosely based on the game [Pocket Dimension](http://www.pocketdimension.com/) for PalmOS 3.
It's a simple dungeon crawler style game that is very much a work-in-progress :)

## Requirements
- Kotlin 1.6

## Browser prototype

A separate Phaser + TypeScript prototype lives in [`web-prototype`](web-prototype).
It is an independent, playable reimagining of the dungeon crawler; it does not
replace or modify the Kotlin desktop game.

```sh
cd web-prototype
npm install
npm run dev
```
